# English Spelling Flashcards — List 11

Digital flashcards for Year 3 English spelling, List 11: when `-ing`, `-en`
and `-ed` are added to multisyllabic words.

- **Spelling test:** Friday 27 November 2026
- **Words:** forgetting, forgotten, beginning, preferred, permitted, regretting, committed, forbidden, propelled, equipped
- **How it works:** tap a card to flip it — front shows the base word + ending and the meaning, back shows the full spelling with the doubled letter highlighted. Mark each word as known or still learning, shuffle the deck, or switch on Test Mode (meaning only — spell the word first, then flip to check).

**Rule:** short vowel + one consonant at the end → double the last letter before adding -ing, -en or -ed. *forget → forgetting, prefer → preferred.*

Open `index.html` in a browser, or visit the GitHub Pages site for this repo. No printing needed — everything is digital.
